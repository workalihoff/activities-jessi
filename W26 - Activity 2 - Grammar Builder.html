Phase 1 — Verb + to + Verb

A small word that makes a big difference: to. Some verbs need it before the next verb — and some never use it.

1These verbs need to

want / need / would like…+to+verb
wantneedwould like ('d like)plantrydecidehave (= must)forgethope
  • I want to finish the report today.
  • We need to check the cut-off times.
  • I'd like to schedule a sync-up.
  • She's planning to loop in Legal.
  • He has to send the file by 5.

2These verbs never use to

can / should / will…+verb
cancouldshouldwillwouldmustmight
  • I can send it this afternoon.
  • You should touch base with the vendor.
  • We will close the loop tomorrow.
  • ✗ I can to send it. · ✗ You should to call him.

3Why is this tricky?

🇬🇹 Español

Quiero enviar el reporte.
Necesito hablar con Marcus.
No connecting word.

🇺🇸 English

I want to send the report.
I need to talk to Marcus.
You need to.

💡 Quick test: Is the first verb can, could, should, will, would, must or might? → No to. Is it want, need, would like, plan, try, have…? → Add to.

4Negatives and questions

The to stays in negatives and questions too:

  • I don't want to miss the deadline.
  • He doesn't need to join the call.
  • What do you need to check with Vinicio?
  • When would you like to pencil in the sync-up?
